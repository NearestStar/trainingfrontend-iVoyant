TypeScript Utility Library

Small utilities. Strong types.

A clean, reusable TypeScript utility library with generic types, predictable APIs, unit tests and an interactive playground.

example.ts 
import {
  capitalize,
  unique,
  sum
} from "ts-utils";

const name = capitalize("bhaskar");

const numbers = unique([1, 2, 2, 3, 3]);

const total = sum(numbers);

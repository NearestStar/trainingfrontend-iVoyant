# Theme Foundry — Ant Design Token Playground

Theme Foundry is an interactive design-system playground built with React, Vite, TypeScript, and Ant Design. It is designed as a fresh Day 21 learning project focused on component libraries, theming, and design tokens rather than another CRUD or task-management app.

## Features

- Live primary-color selection and named color presets
- Controls for border radius, base font size, and component control height
- Light/dark mode and compact-density switches
- Live previews of Ant Design buttons, cards, inputs, select, date picker, tags, alert, progress, switch, avatars, and other components
- Token JSON view with a copy action
- Central theme configuration using `ConfigProvider`
- Component-level token overrides for buttons and inputs
- Responsive layout for desktop, tablet, and mobile screens

## Requirements

- Node.js compatible with the installed Vite version
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Create a production build

```bash
npm run build
npm run preview
```

## Learning checklist

1. Change `colorPrimary` and watch all themed components update.
2. Change `borderRadius`, `fontSize`, and `controlHeight`.
3. Toggle the dark and compact theme algorithms.
4. Switch between the live preview and token JSON.
5. Inspect `src/App.tsx` to see how the `ThemeConfig` object is passed to `ConfigProvider`.
6. Inspect `src/components/TokenControls.tsx` to see controlled Ant Design inputs update React state.
7. Inspect `src/components/TokenJson.tsx` to see how the current tokens are exported as JSON.

## GitHub and hosting

Create a repository on GitHub and run these commands from the project folder (replace the URL with your repository URL):

```bash
git init
git add .
git commit -m "Build Theme Foundry design token playground"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/theme-foundry.git
git push -u origin main
```

Then import the repository into Vercel or Netlify and deploy it as a Vite application. Use `npm run build` as the build command and `dist` as the output directory. A public Git repository and hosted URL must be created in your own account; they are not generated by this local project ZIP.
